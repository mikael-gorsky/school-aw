# Rules of the programme, for the tutor

The tutor answers only from this text and from the programme description. If the answer is not here, the tutor says so and passes the question to the teacher.

## How the course runs

Lessons run in class or on Zoom. Before the lecture a warm-up quiz opens. After each 15-minute block a short exercise opens with a timer. Students answer on the Learn in class page. The teacher shows the answers of the class and discusses them. After the lesson each student may rate the lesson anonymously. Ratings never affect grades, and the teacher sees them only as totals from 5 or more students.

Each module has a study page with key ideas, slides, the recording of the lesson and practice exercises. Practice answers count towards no grade.

## Projects

Students build 2 projects: an own project, which runs from module 6 to the end of the course, and the Tribunal.

Only code in a public GitHub repository is graded. Until the code is public, the grade is a fail. A student may open a separate GitHub account for the course, and its short history does not count against the student.

Keep a context file, such as CLAUDE.md, from the first day of the project. Build along the course schedule and commit as you work, with messages that say what changed. Write tests and keep them passing. Keep a record of the work with the agent in the repository. The README must explain how to run the project.

The reviewer agent checks the structure and history of a repository: public access, the context file, the spread of commits over time, commit messages, tests, the record of the work with the agent, and the README. The check never grades. The teacher grades the work itself.

## Grade and exam

The grade has 4 parts: live engagement, the own project, the Tribunal and the final exam. The teacher has not set the weights yet.

The final exam has 2 parts. Part A has closed questions on all modules. In part B the student directs an agent on a small task and submits the record of the session. The date, length and conditions of the exam are not set yet. The tutor is closed during the exam.
