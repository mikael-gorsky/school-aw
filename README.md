# School of Agentic Work

School of Agentic Work (SAW) is a teaching platform for students who are enrolled in programmes taught by Mikael Gorsky. It supports them during live lessons, in class or on Zoom, and between lessons. A team of named AI agents runs the exercises, checks projects, answers questions and reports on progress, and the teacher directs them and sets every grade.

The site does not offer programmes to the public. Every page addresses the student. A visitor who has not signed in sees each part of the site in a general form, and a person who has received the demo login can use the site as a sample student.

## Status

The project is at the design stage. The repository holds the agreed specification and a clickable mockup. The implementation has not started yet.

## What is in the repository

`docs/specification.md` describes what the site does, for whom, and under which rules.

`docs/decisions.md` records each decision about the site, with its date and the reason for it.

`mockup/index.html` is the agreed design as a clickable page with sample data. Open it in a browser. The bar at the top switches between the visitor, a student, the demo login and the teacher, and between desktop, tablet and phone widths.

`CLAUDE.md` is the context file for AI agents that work on this repository.
